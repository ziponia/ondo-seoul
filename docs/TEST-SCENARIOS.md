# 테스트 시나리오 체크리스트

모든 시나리오는 **데모 모드에서 데이터 없이** 돌릴 수 있어야 한다(`pnpm dev:demo`, `docs/DEMO.md`). 실제 상점 연결(`npx sayren link`) 뒤에는 같은 시나리오를 상점 데이터로 한 번 더 확인한다.

- 시나리오 전환: 데모 모드 화면 아래의 데모 패널, 또는 주소에 `?demo=<시나리오>`
- 자동: `pnpm test`가 확인하는 항목. 수동: 브라우저에서 데스크톱(1440)·모바일(390) 두 폭으로 확인

상태: 미확인 · 통과
